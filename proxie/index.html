Proxie

Proxie builds one structured, sourced model of everything a professional has done. Every surface reads from it: a portfolio site, a skill galaxy, an AI representative and a brief that fits their record to a specific role.

The idea

Experienced professionals carry more value than a resume can show, including how they think and why the things they built worked. A resume flattens that. Proxie moves a person's value from something they know about themselves to something an evaluator can read and check against its sources.

Articulate inwardAn intake that works like coaching. The person understands their own value better before anyone opens their link.
Translate outwardA structured model renders that value in terms an evaluator can read and act on.
Connect to needGiven a specific role, Proxie frames the person's evidence against what the role requires, and names the gaps.
ProveEvery claim already traces to its source. A later verification product can upgrade claims from sourced to verified.

The pieces

One model feeds every surface under the same access rules. Each piece below is marked live, in use, designed or planned.

The interview that builds the model DesignedIn use for the first profile

  • Intake is modular. A resume, a LinkedIn data export, project portfolios, an intake interview and a Remix Career profile all normalize into the same model.
  • Quick Start will put a working public representative live in about ten minutes, from a few questions and a resume.
  • The full interview runs in sessions. One covers how the person works. Then each significant role gets its own narratives, such as the hardest problem and what changed how they work.
  • Before going live, a pre-screener reads everything and lists the questions a hiring manager will almost certainly ask, such as a gap or a short tenure. The person answers each in advance, and those answers come first when the question comes up.
  • The first profile was built this way, from a two-day interview plus a resume, documents and code repositories. It holds eight capability families and about 50 skills, each tied to the roles and projects that prove it.

The Person Model In use

  • A structured, cross-linked model in place of a pile of text. Roles, projects, capabilities, accomplishments and stories link to each other and to the sources behind them.
  • Every unit is addressable two ways. Ask about one role and get everything attached to it. Ask about one capability and follow it across a whole career, in order.
  • Plain document search can't do either reliably. It returns the most similar passages, not the complete set, and it has no sense of time.
  • Each unit carries an access tier, a flag for the person's own quotable words and a permanent record of where it came from.
  • It works as a contract between products. The portfolio site reads it at build time today, and the representative will read the same files.

The AI representative Designed

  • A conversational representative a professional shares by link. It will speak about them in the third person, the way an informed advocate would, so it never puts invented words in their mouth.
  • Retrieval will pick a strategy for each question: a complete answer about one role, a capability traced over time, a pre-screened hard question or a question about fit.
  • Its guardrails are hard limits. It never invents experience, never shares anything marked private, never speculates about salary and never disparages anyone.
  • When it can't answer well, it hands off with a way to contact the person and a way to keep exploring.

Access codes and engagement LiveDashboard designed

  • Every recipient gets their own code, typed in or built into a link. Codes are stored only as hashes, with expiry, use limits and instant revocation.
  • Deep content never reaches a browser without a valid code. The server filters by tier before anything is sent.
  • Because each code belongs to one recipient, the person can see who opened the site and which pages they read.
  • The designed dashboard adds what visitors asked and which parts of the record get retrieved most, so the person learns what evaluators respond to.

The translation layer Designed

  • Attach a job description to an access code and the representative will frame the person's experience against that role. Each requirement maps to evidence from the record.
  • Gaps are acknowledged constructively. Translation never becomes embellishment.

The Remix Career connector Designed

  • A Remix Career profile arrives already translated: archetype, behavioral dimensions, purpose statement and skills analysis. Importing one will shorten the behavioral interview.
  • The connection is a versioned export the user starts. The two products share no code and no database, so each stays free to change.

The portfolio site and the skill galaxy Live

  • The first Proxie site is live: the portfolio of Joshua Sturtevant, founder of Building The Future Digital Labs. Its home page pairs a written profile with a 3D galaxy of his capabilities.
  • The galaxy runs from capability families to skills to the roles and projects that prove each one. Click a star and the camera flies to it while its children open around it.
  • Every focus has its own URL, and the back button flies out a level. A list view gives the same content to screen readers, and reduced-motion settings swap the camera flights for crossfades.
  • Planned: Proxie generates a site like this from anyone's Person Model, with the representative built in.

Where it goes Planned

  • Multi-tenant from the first commit. Each professional is a tenant. Professionals subscribe, and recruiters and hiring managers use it free.
  • An embeddable widget for a resume, a LinkedIn profile, a portfolio or an email signature.
  • A verification product that plugs into Proxie's API to upgrade claims from sourced to verified.
